Статус: активный проект.

Цель — подготовить поездку в Томск до конца ноября: выбрать даты, забронировать жильё и составить маршрут. После завершения перенести материалы проекта в архив.

## Следующие действия

- Согласовать даты с участниками.
- Проверить варианты жилья.
- Записать план прогулки по городу.
