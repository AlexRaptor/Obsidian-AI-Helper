# Тестовое хранилище для упоминаний заметок

Исходные данные находятся в `create-vault.mjs`. Генератор создаёт новое хранилище с восемью заметками, русскоязычным содержимым, контрольными метками, одинаковыми названиями в разных папках и путями для согласованных примеров поиска `project monexa` и `projemonex`.

Генератор копирует текущие `main.js`, `manifest.json` и `styles.css` в папку плагина по идентификатору из манифеста. Существующую папку не перезаписывает. Адрес сервера, модель и ключ не задаёт; папка `Личное` исключена из индексации для проверки явного выбора без индекса. Новые хранилища `vault*` внутри этого каталога исключены из Git.

Подготовка и восстановление описаны в [инструкции ручной проверки](../../testing/note-mentions/setup.md). Это только данные для проверки: реализация упоминаний пока не выполнена.
