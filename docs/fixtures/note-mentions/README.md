# Тестовое хранилище для упоминаний заметок

Исходные данные и генератор находятся рядом со сценариями: [create-vault.mjs](../../testing/note-mentions/create-vault.mjs). Старый путь генератора сохранён для совместимости. Генератор создаёт новое хранилище с восемью заметками, русскоязычным содержимым, контрольными метками, одинаковыми названиями в разных папках и путями для согласованных примеров поиска `project monexa` и `projemonex`.

Генератор копирует текущие `main.js`, `manifest.json` и `styles.css` в папку плагина по идентификатору из манифеста. Существующую папку не перезаписывает. Адрес сервера, модель и ключ не задаёт; папка `Личное` исключена из индексации для проверки явного выбора без индекса. Тестовое хранилище создаётся в `docs/testing/note-mentions/current-note-vault/` и исключено из Git.

Подготовка и восстановление описаны в [инструкции ручной проверки](../../testing/note-mentions/setup.md). Сценарий текущей заметки реализован в #35; жизненный цикл выбранных файлов проверяется в #39 по [сценарию](../../testing/note-mentions/file-lifecycle.md) в отдельном `docs/testing/note-mentions/file-lifecycle-vault/`. Генератор и исходные данные общие для этих сценариев.
