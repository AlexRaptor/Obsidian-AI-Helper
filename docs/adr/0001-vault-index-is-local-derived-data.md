# Индекс хранилища — локальные восстанавливаемые данные

Индекс поиска по заметкам сохраняется между запусками, но может быть удалён и построен заново из заметок; его перенос и синхронизация между компьютерами не входят в первую версию. По умолчанию индекс хранится локально в приложении, отдельно от файлов хранилища, чтобы синхронизация заметок через Git не переносила большой производный индекс; дополнительный файловый режим требует явного выбора и исключения из Git. Это сокращает объём синхронизируемых данных ценой отдельной индексации на каждом компьютере; доступность и сохранность локального хранилища проверяются в настольном Obsidian до реализации, без автоматического переключения на файловый режим.
