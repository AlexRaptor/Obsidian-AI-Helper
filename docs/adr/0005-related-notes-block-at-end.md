# Блок связанных заметок дополняется только в конце заметки

Подтверждённые смысловые связи сохраняются обычным Markdown в блоке с невидимыми HTML-маркерами границ; плагин дополняет его только тогда, когда после закрывающего маркера нет непробельного текста. Если пользователь переместил блок или дописал текст ниже, прежний блок сохраняется, а новый создаётся в конце: это сохраняет предсказуемое место добавления ценой нескольких блоков в одной заметке; поиск и дополнение блока в произвольном месте отвергнуты. Ссылки из всех блоков учитываются для предотвращения дублей, а блоки с корректными маркерами исключаются из смыслового анализа, чтобы ранее сгенерированные объяснения не становились основанием новых предложений.
