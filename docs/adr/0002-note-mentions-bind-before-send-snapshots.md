# Упоминание выбирает заметку, отправка сохраняет её снимок

Упоминание в черновике привязывается к выбранной заметке при добавлении, но её содержимое читается на момент отправки: это учитывает правки, сделанные во время подготовки вопроса, и предотвращает подмену заметки при переключении вкладок. Отправленный снимок сохраняется с сообщением в истории диалога, чтобы последующие вопросы относились к тому же содержимому; дальнейшие правки исходной заметки не переписывают историю. Это увеличивает объём контекста по сравнению с передачей заметки только в одном запросе, но позволяет последовательно обсуждать её без повторного прикрепления.
