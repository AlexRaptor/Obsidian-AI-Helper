# Текст выделенного фрагмента фиксируется при добавлении упоминания

В отличие от целых заметок, содержимое которых читается при отправке согласно ADR-0002, текст выделенного фрагмента фиксируется при подтверждённом добавлении упоминания в черновик. Последующие правки заметки или смена выделения не изменяют добавленный текст: это позволяет собирать несколько конкретных фрагментов из разных заметок без подмены ранее выбранного контекста. Повторное выделение и добавление позволяет передать новую версию; отслеживание изменяющегося диапазона до отправки отвергнуто ради предсказуемости явно выбранного текста.
