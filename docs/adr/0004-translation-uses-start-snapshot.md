# Перевод работает с полным снимком на момент запуска

Операция перевода фиксирует содержимое оригинала, его имя и расположение, цели ссылок и все используемые настройки на момент запуска; последующие правки, переименования, перемещения, удаления и изменения настроек не меняют её исходные данные. Это позволяет переводить части и повторять неудавшиеся запросы на одной основе без смешивания версий, ценой возможной неактуальности сохранённых путей; отслеживание оригинала после запуска отвергнуто, для учёта изменений пользователь прерывает операцию и запускает новую. Снимок и готовые части живут только в текущей операции: восстановление после перезапуска и продолжение из сохранённого неполного перевода не входят в первую версию.
