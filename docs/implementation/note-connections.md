# Первая порция поиска связей — #60

Команда `find-note-connections` фиксирует файл, путь и актуальный текст Markdown-редактора до открытия чата. Отдельная операция панели не использует историю диалога и не изменяет заметки. Выбор, сохранение, папочные области, настройка размера порции и анализ больших заметок относятся к следующим задачам.

Отбор использует только актуальные записи существующего индекса с совместимым отпечатком настроек. Исключения проверяются до чтения. Исходная заметка и цели уже существующих ссылок удаляются из кандидатов. Допускается актуальная часть индекса с предупреждением. Обычный поиск не изменён.

Конечный набор — до 24 заметок, у каждой до трёх наиболее похожих фрагментов. Порядок: убывание максимального косинусного сходства, затем путь; внутри заметки — убывание сходства, затем текст. Порог сходства и бюджет источников обычного поиска не применяются. Низкое сходство не запрещает предложение. Кандидаты проверяются последовательно до пяти полезных предложений или исчерпания набора.

Модель получает полный очищенный текст исходной заметки и фрагменты одного кандидата с заголовками как недоверенные JSON-данные. Ответ — объект `{ "candidate": "cN", "explanation": "…" }`; `null` вместо объяснения отклоняет связь. Принимается только завершение `stop`. Неизвестный идентификатор, иная структура, пустое объяснение, Markdown, HTML, ссылки и маркеры блоков вызывают отказ от публикации всей порции. Объяснения отображаются текстом. При отсутствии полезных связей карточки не создаются. Автоматика проверяет протокол и привязку к кандидатам; смысловую точность произвольной модели гарантировать невозможно.

Бюджет проверяется консервативно по UTF-8-размеру сериализованных сообщений, с резервом ответа и 256 токенами запаса. При неизвестном окне или превышении бюджета — явный отказ без обрезания и запасного поиска. На время подготовки и запросов используется общий доступ `ConversationModel`; отмена немедленно освобождает его, поздние ответы игнорируются.

## Контракт блоков для последующего сохранения

Маркеры едины для языков:

```md
<!-- ai-helper:related-notes:start -->
## Связанные заметки
- [[Цель]] — Объяснение.
<!-- ai-helper:related-notes:end -->
```

`relatedNotesBlocks` из `src/related-notes-markdown.ts` возвращает текст без корректных блоков, их диапазоны `[start, end)` в исходной строке и признак `malformed`. Маркер занимает отдельную строку с максимум тремя начальными пробелами; после него допустимы пробелы и перевод строки или конец файла. Заголовок не участвует в распознавании. Примеры маркеров внутри кода игнорируются. Незакрытые, лишние, вложенные и неканонические маркеры дают `malformed`; неоднозначные участки не удаляются как корректные блоки. Будущий путь сохранения должен отказывать при `malformed`, дополнять только блок с пробельным остатком после него и следовать ADR-0005.

При анализе удаляются все корректные блоки, включая перемещённые. Для дедупликации ссылки извлекаются из исходного текста, включая эти блоки, с разрешением целей через публичный `metadataCache.getFirstLinkpathDest`. Кэш ссылок не используется: текст редактора может быть новее. Если запись индекса содержит блоки, фрагменты и их векторы пересчитываются по очищенному материалу только этой уже проиндексированной, актуальной и разрешённой заметки; прежние объяснения не влияют на ранжирование и не отправляются модели.
