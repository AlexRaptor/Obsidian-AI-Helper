Для воспроизводимого сбоя используется консоль разработчика **только в отдельном тестовом хранилище**. Подменяется внешняя операция Obsidian; сценарий плагина остаётся настоящим. Это ручные действия пользователя, агент их не выполнял.

1. Откройте новый чистый набор. Откройте Developer Tools (macOS: Cmd+Option+I), вкладку Console. Вставьте:

```js
(() => {
  const fm = app.fileManager;
  const original = fm.renameFile;
  let successful = 0;
  fm.renameFile = async function(file, path) {
    if (path.endsWith('about.md')) {
      if (successful === 1) throw new Error('issue27: controlled forward failure');
      await original.call(this, file, path);
      successful++;
      return;
    }
    return original.call(this, file, path);
  };
  window.issue27Restore = () => { fm.renameFile = original; delete window.issue27Restore; };
})();
```

2. Через настройку выберите переименование в `about.md`. После первого успешного переноса следующий завершается ошибкой.

## 5. Сбой восстановления с точными путями

1. Откройте новый чистый набор и Console. Вставьте:

```js
(() => {
  const fm = app.fileManager;
  const original = fm.renameFile;
  let renamed = null;
  let originalPath = null;
  fm.renameFile = async function(file, path) {
    if (path.endsWith('about.md')) {
      if (renamed) throw new Error('issue27: controlled forward failure');
      originalPath = file.path;
      await original.call(this, file, path);
      renamed = file;
      return;
    }
    if (file === renamed && path === originalPath) throw new Error('issue27: controlled rollback failure');
    return original.call(this, file, path);
  };
  window.issue27Restore = () => { fm.renameFile = original; delete window.issue27Restore; };
})();
```

2. Через настройку запустите переименование в `about.md`. Первый файл переименован, второй перенос и возврат первого завершаются ошибками.
3. Диалог сообщает о **неполном** восстановлении, не сообщает о полном успехе отката. Показаны точный текущий и исходный путь первого файла (`…/about.md → …/_folder.md`; какой файл будет первым, зависит от порядка Obsidian). Убедитесь, что путь совпадает с фактическим файлом в проводнике. Остальные описания сохранили старые имена, настройка `_folder.md`.
4. Скопируйте показанные пути в протокол проверки. Выполните `window.issue27Restore()` и отмените диалог. Вручную через Obsidian верните оставшийся `about.md` в показанный `_folder.md`; проверьте ссылки и содержимое.
