В настройках плагина указать свой OpenAI-совместимый модель-сервер, ключ при необходимости и модель диалога с поддержкой инструкций о JSON. Embedding-модель и индекс не нужны. Тестовые тексты будут переданы выбранному модель-серверу.

В Obsidian: Files and links → Automatically update internal links включено; New link format → Absolute path in vault. Если настройка обновления ссылок выключена, повторить сценарий ссылок отдельно, разрешая обновление при нативном запросе Obsidian. При отказе ожидается сохранение прежних ссылок согласно настройкам Obsidian.

## Сценарии

1. **Явный перенос и ссылки.** Открыть `Inbox/Метод.md` в основном редакторе; из палитры выполнить «Предложить папку для текущей заметки». Дождаться рекомендации `Справка`. До нажатия кнопки файл остаётся в Inbox. Нажать «Перенести в эту папку» в кандидате `Справка`. Ожидание: сообщение «Заметка перенесена», путь `Справка/Метод.md`, исходного файла нет; свойства, заголовок, тело и исходящая ссылка `[[Связи/Обзор]]` сохранены. В `Связи/Обзор.md` ссылка, Markdown-ссылка и встраивание открывают перенесённую заметку; при включённом автоматическом обновлении пути обновлены Obsidian. Основной редактор показывает перенесённый файл. Рекомендация сама не выполняет файловых действий.
2. **Прежние рекомендации.** На свежем наборе анализировать `Inbox/Метод.md`, затем изменить свойство `статус` и добавить абзац `Правка пользователя перед переносом.`. Ожидание: отметка устаревания и отдельная кнопка «Перенести по прежним рекомендациям», обычная кнопка заменена. Нажать её у `Справка`. Повторный анализ не требуется; `Справка/Метод.md` содержит новые свойство и абзац. Повторить с другим новым набором, но выбрать «Обновить рекомендации»: анализируется текущая версия, после ответа перенос доступен обычной кнопкой.
3. **Изменившиеся описания.** На новом наборе получить рекомендации для `Inbox/Метод.md`; изменить `Справка/_folder.md`, затем попробовать перенос по прежним рекомендациям. Ожидание: отказ «Описание изменилось», файл остаётся в Inbox, необходимо обновить рекомендации. Повторить с изменением `Дневник/_folder.md` — оно тоже участвовало в анализе, даже если модель не выбрала Дневник. Повторить с новым содержательным описанием в новой папке. Старые рекомендации не разрешают обход изменений описаний.
4. **Конфликт и открытие файла.** На новом наборе анализировать `Inbox/Конфликт.md`, выбрать кандидата `Справка`, нажать перенос. Ожидание: «Перенос остановлен», точный путь `Справка/Конфликт.md` и кнопка «Открыть существующий файл». Нажать её: открывается заметка с текстом `ЭТОТ ТЕКСТ НЕЛЬЗЯ ПЕРЕЗАПИСЫВАТЬ.`. Оба файла остаются на местах и не меняются, автоматического переименования нет. Если кандидат не предложен, обновить анализ; качество выбора модели оценивать отдельно от механики переноса.
5. **Отсутствующий исходный файл.** На новом наборе получить рекомендации для `Inbox/Метод.md`, удалить исходный файл через Obsidian и попробовать перенос в оставшейся панели. Ожидание: сообщение об отсутствии заметки, успешного переноса нет, новый файл не создаётся. Затем открыть другую заметку и запустить команду: панель снова работает.
6. **Отсутствующая папка.** На новом наборе получить рекомендации для `Inbox/Метод.md`, удалить папку `Справка` через Obsidian, нажать перенос в оставшейся панели. Ожидание: отказ об отсутствии назначения; папка не создаётся автоматически, `Inbox/Метод.md` сохранён. Если изменились и описания, допустимо требование обновить рекомендации; успешного переноса быть не должно.
7. **Без фиктивного перемещения и доступность.** Анализировать `Дневник/Сегодня.md`, затем `Inbox/Нет папки.md`. При результатах «Оставить в текущей папке» / «Подходящей папки нет» кнопок переноса нет. Если модель предлагает текущую папку кандидатом, нажатие сообщает «Оставить в текущей папке» и файл остаётся на месте. Сузить панель, проверить доступность кнопок и перенос путей; проверить светлую/тёмную тему и английский интерфейс. Повторное быстрое нажатие не создаёт второй перенос.

## Результаты

Для каждого сценария записать фактический результат, версию Obsidian, модель-сервер, модель диалога, окно контекста и настройку обновления ссылок. Автоматические проверки и подготовку хранилища не считать прохождением ручных сценариев.
