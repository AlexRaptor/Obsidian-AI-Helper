# Дополнительная ручная проверка #74

Ручная проверка не является обязательной приёмкой #74: поведение покрыто автоматическими проверками через ChatView. Эти сценарии нужны, если хочется проверить понимание русских поручений реальной моделью диалога и результат в Obsidian. Выполняет пользователь.

## Подготовка и восстановление для всех сценариев

Исходные данные: `/Users/selivanov/code/Obsidian-AI-Helper/docs/testing/chat-material-search/notes/`.

Общее хранилище для каждого сценария ниже: `/Users/selivanov/code/Obsidian-AI-Helper/docs/testing/chat-material-search/notes-vault/`.

Закройте это тестовое хранилище в Obsidian перед подготовкой или восстановлением. Из корня репозитория выполните:

```sh
python3 docs/testing/prepare_vault.py --source docs/testing/chat-material-search/notes --dest docs/testing/chat-material-search/notes-vault
```

При первом запуске генератор соберёт плагин и установит его в тестовое хранилище. Откройте эту папку как хранилище Obsidian, отключите ограниченный режим и включите Obsidian AI Helper. Настройте модель диалога с поддержкой вызова инструментов и embedding-модель. Настройки и секреты других хранилищ генератор не переносит. Укажите корректное окно контекста или дождитесь автоматического определения. Оставьте «Бюджет источников» равным 12000. Нажмите «Проиндексировать хранилище» и дождитесь завершения.

Перед каждым независимым сценарием очистите чат. Для восстановления заметок повторите команду выше и выберите режим 3 («Заменить только контент»), затем откройте хранилище заново и обновите индекс. Для обновления плагина после изменения кода используйте режим 2. Режимы 1–3 удаляют прежние заметки и вложения тестового хранилища за пределами `.obsidian`; используйте только указанную тестовую папку.

## 1. Включённый переключатель сам по себе не разрешает поиск для записи

В общем хранилище включите «Поиск по заметкам», но не отправляйте предварительных поисковых вопросов. Напишите:

> Создай заметку «Итог без поиска». Используй только это поручение: едем поездом, дату ещё не выбрали. Дополнительный поиск не выполняй.

Ожидание: создана одна заметка со ссылкой в чате. В ней есть только переданные условия; отсутствуют код СЕВЕР-74, время 18:30 и бюджет 3000 рублей. Обязательного предпросмотра или подтверждения нет. Сам переключатель может остаться включённым.

Этот сценарий даёт видимый признак отсутствия подмешивания; отсутствие самого поискового запроса надёжнее подтверждает автоматический тест. После проверки восстановите общее хранилище по инструкции выше.

## 2. Явный поиск и создание при выключенном переключателе

В общем хранилище выключите «Поиск по заметкам». Напишите:

> Найди в хранилище материалы о подготовке поездки в Северогорск и создай заметку «Сводка поездки». Включи время отправления, список вещей, расходы, открытые вопросы и контрольный код из найденных материалов.

Ожидание: создана заметка, в чате есть ссылка. Результат опирается на материалы: 18:30, паспорт/зарядное устройство/термос, 3000 рублей, неподтверждённая гостиница, СЕВЕР-74. Если модель сообщает о недостающих материалах, проверьте состав фактической выдачи; отсутствие части найденных сведений нельзя маскировать выдумкой. Заметки в `Материалы/` не изменились. После проверки восстановите общее хранилище.

## 3. Явный поиск и дополнение прикреплённой цели

В общем хранилище откройте `Проверка/План.md`. Через `@` прикрепите именно эту заметку и отправьте:

> Найди материалы о подготовке поездки в Северогорск и дополни прикреплённый План списком вещей и расходами. Сохрани прежний текст и свойства. Найденные заметки не изменяй.

После отправки можно переключить активную вкладку на материал.

Ожидание: изменён `Проверка/План.md`; YAML `статус: черновик` и строка «Сохранить эту строку при дополнении плана» остались. Активная вкладка не подменила цель. Материалы остались исходными. После проверки восстановите общее хранилище.

## 4. Только выделенный фрагмент, без скрытых соседей

В общем хранилище откройте `Проверка/Фрагмент.md`. Выделите только «Купить билет на поезд в Северогорск.». Через `@@` прикрепите выделение. Отправьте:

> Найди дополнительные материалы о подготовке поездки в Северогорск и дополни только прикреплённый фрагмент временем отправления и списком вещей. Остальной текст заметки не используй. В ответе перечисли личные коды из полученных материалов, если они там есть; не угадывай.

Ожидание: изменён только выбранный абзац; обе строки `СКРЫТЫЙ_СОСЕД` сохранены. В новом тексте и ответе нет ЛИПА-852 и КЕДР-963. Соседние строки должны оставаться в исходном файле — это не утечка. Модель может сообщить, что личных кодов не получала. Код СЕВЕР-74 из отдельного поискового материала допустим.

Для дополнительного случая сначала обсудите целую заметку с безобидными соседями, затем замените соседние строки новыми личными кодами, прикрепите только выделенный абзац и повторите поручение. Новые соседние коды также не должны попасть модели. Для случая переименования сначала обсудите прикреплённый фрагмент, переименуйте заметку, обновите индекс и поручите поиск с дополнением того же фрагмента из истории. Скрытые соседи не должны появиться в ответе. После проверки восстановите общее хранилище.

## 5. Ошибка обязательного поиска не выдаётся за успех

В общем хранилище временно задайте «Бюджет источников» равным `1`, оставив рабочие настройки модели диалога. Отправьте:

> Найди материалы о поездке в Северогорск и создай по ним заметку «Проверка ошибки».

Ожидание: сообщение о нехватке бюджета; заметка «Проверка ошибки» не создана, утверждения об успешном использовании материалов нет. Верните бюджет 12000.

Для сетевой ошибки можно временно сделать недоступным только сервер embedding-модели, сохранив рабочим сервер модели диалога, и повторить поручение в новом чате. Ожидание то же: поиск завершился ошибкой, запись не выполнена. Восстановите соединение. После проверки восстановите общее хранилище.

## 6. Ручное изменение цели во время подготовки

В общем хранилище прикрепите `Проверка/План.md` через `@` и попросите найти материалы и дополнить план. Пока модель ещё готовит результат, допишите в целевую заметку «Ручная правка: дату согласовать со мной».

Ожидание: если изменение произошло до записи инструмента, плагин останавливает правку с сообщением о конфликте, ручной текст остаётся. Автоматической повторной правки с новой основой нет. Если модель успела записать раньше ручного ввода, сценарий не проверил конфликт; восстановите общее хранилище и повторите. Детерминированный случай уже покрыт автоматическим тестом.
