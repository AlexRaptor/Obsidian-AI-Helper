# Подготовка поездки в Северогорск

Для поездки в Северогорск нужно купить билет за семь дней до отправления.
Взять паспорт, зарядное устройство и термос.
Поезд отправляется в 18:30, прибыть на вокзал следует к 18:00.

Контрольный код подготовки поездки: СЕВЕР-74.
Этот код нужен только для проверки того, что материал действительно найден.
