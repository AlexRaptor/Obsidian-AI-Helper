# №71: отдельная отмена вставки

Автоматические проверки через ChatView покрывают фиксацию позиции и полной основы при отправке, разные источник и цель, вставку в конец цели из истории, конфликты, идентичность файла, открытие редактора, остановку и новую версию результата. Ручная проверка нужна только для реальной группировки отмены и повтора в Obsidian: заменитель API и отдельная история CodeMirror не воспроизводят интеграцию полностью. Проверку выполняет пользователь.

## Подготовка и восстановление

Исходные данные: `/Users/selivanov/code/Obsidian-AI-Helper/docs/testing/chat-note-actions/notes/`.

Тестовое хранилище: `/Users/selivanov/code/Obsidian-AI-Helper/docs/testing/chat-note-actions/insertion-vault/`.

Закройте это тестовое хранилище перед подготовкой или восстановлением. Из корня репозитория выполните:

```sh
python3 docs/testing/prepare_vault.py --source docs/testing/chat-note-actions/notes --dest docs/testing/chat-note-actions/insertion-vault
```

Первый запуск собирает и устанавливает текущий плагин. Настройте подключение к модель-серверу с поддержкой инструментов в тестовом хранилище. Генератор не переносит секреты и настройки других хранилищ. После изменения кода выберите режим 2: восстановить материалы, обновить плагин, сохранить настройки. Между сценариями выберите режим 3: восстановить материалы, сохранив плагин и настройки. Режимы 1–3 удаляют прежний тестовый контент вне `.obsidian`. После восстановления откройте хранилище заново для новой истории отмены и нового диалога.

## Вставка у курсора рядом с ручной правкой

1. Откройте `Проверка/План.md` в редакторе. В конце вручную допишите «Ручная метка до вставки».
2. Поставьте один курсор после строки «Место вставки: поставьте курсор после этой строки.». Перейдите в чат и отправьте: «Вставь у курсора отдельной строкой: Проверить документы».
3. После сообщения «Изменена заметка» вернитесь в редактор. Одно Cmd/Ctrl+Z должно убрать только вставку, сохранив ручную метку, свойства, остальной текст и ссылку. Обычный повтор возвращает вставку одним действием.
4. Вручную добавьте «Ручная метка после вставки». Первая отмена убирает только эту метку, вторая — только вставку. Повторы возвращают их раздельно.

Перед следующим сценарием восстановите это же хранилище указанной командой, режим 3.

## Замена фрагмента и следующая вставка

1. Откройте `Проверка/План.md`. Выделите абзац, начинающийся «Мы собираемся отправиться в поездку на поезде…». В чате введите «Замени прикреплённый фрагмент кратким списком дел @@», подтвердите вложение клавишей Tab и отправьте.
2. После успеха поставьте курсор после строки «Место вставки…», перейдите в чат и отправьте: «Вставь у курсора отдельной строкой: Проверить документы».
3. Одна отмена удаляет только вставку. Следующая отмена восстанавливает исходный абзац вместо списка. Два повтора раздельно возвращают список и вставку. Свойства и соседний текст сохраняются.

Перед следующим сценарием восстановите это же хранилище указанной командой, режим 3.

## Вставка в конец закрытой цели из истории

1. В чате прикрепите `Проверка/Материал.md` через `@`, отправив «Обсудим прикреплённую заметку». Закройте её вкладку.
2. Отправьте отдельное поручение: «Добавь в конец ранее прикреплённой заметки “Материал” отдельной строкой: Материал проверен».
3. В редакторе, открытом плагином для записи, одна обычная отмена убирает только добавленную строку, повтор возвращает её. Исходный текст и свойства сохраняются.

При несоответствии достаточно сообщить сценарий, шаг и фактическое поведение. Остальные требования подтверждаются автоматическими проверками.
