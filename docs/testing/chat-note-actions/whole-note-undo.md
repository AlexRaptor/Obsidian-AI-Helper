# №69: обычная отмена правки целой заметки

Автоматические проверки подтверждают протокол, версии, YAML, идентичность файла, остановку и повторную проверку после открытия редактора. Ручная проверка нужна только для реальной истории отмены Obsidian: заменитель его API не воспроизводит интеграцию редактора и группировку транзакций. Её выполняет пользователь; до этого №69 остаётся открытым.

## Подготовка и восстановление

Исходные данные: `/Users/selivanov/code/Obsidian-AI-Helper/docs/testing/chat-note-actions/notes/`.

Хранилище: `/Users/selivanov/code/Obsidian-AI-Helper/docs/testing/chat-note-actions/whole-note-vault/`.

Закройте это тестовое хранилище перед подготовкой или восстановлением. Из корня репозитория:

```sh
python3 docs/testing/prepare_vault.py --source docs/testing/chat-note-actions/notes --dest docs/testing/chat-note-actions/whole-note-vault
```

Первый запуск собирает и устанавливает текущий плагин. Подключение к модель-серверу с поддержкой инструментов настройте в тестовом хранилище; секреты других хранилищ не переносятся. Для обновления реализации выберите режим 2 (восстановить материалы, пересобрать плагин, сохранить настройки); между сценариями — режим 3 (восстановить материалы без сборки). Эти режимы удаляют тестовый контент вне `.obsidian`. После восстановления откройте хранилище заново: начнутся новая история отмены и новый диалог.

## Целая заметка и соседний ручной ввод

1. Откройте `Проверка/План.md` в редакторе и допишите «Ручная метка до правки».
2. В чате прикрепите целую заметку через `@` и поручите: «Исправь в прикреплённой заметке фразу “Мы собираемся отправиться в поездку на поезде” на “Мы поедем на поезде”. Остальное сохрани».
3. После фактического результата «Изменена заметка» вернитесь в редактор. Одна Cmd/Ctrl+Z отменяет только правку модели и сохраняет ручную метку. Обычный повтор возвращает только правку модели.
4. Допишите «Ручная метка после правки». Проверьте, что она и правка модели отменяются отдельными действиями в обратном порядке и раздельно возвращаются повтором. YAML и остальной текст сохраняются.

Перед следующим сценарием восстановите это же хранилище приведённой командой, режим 3.

## Закрытый редактор, последовательные правки и независимость заметок

1. Прикрепите `Проверка/План.md` и `Проверка/Материал.md` в сообщении «Обсудим эти материалы». Дождитесь ответа и закройте вкладки обеих заметок, оставив чат открытым.
2. Поручите: «Добавь в конец заметки “План” строку “План проверен”, сохрани остальное». Плагин откроет редактор именно этой заметки. В нём проверьте, что одна отмена убирает только добавление, а повтор возвращает его.
3. Отдельным следующим сообщением поручите: «Добавь в конец той же заметки строку “Билеты проверены”». Две обычные отмены убирают эти две правки по одной; два повтора возвращают их раздельно. Не делайте новое поручение между отменой и повтором: ручная отмена меняет ожидаемую версию.
4. Отдельным сообщением поручите: «Добавь в конец заметки “Материал” строку “Материал проверен”». В открытом для этой цели редакторе одна отмена убирает только эту строку, повтор возвращает её. Содержимое заметки “План” не меняется.

При несоответствии достаточно сообщить сценарий, шаг и фактическое поведение. Сценарии фрагмента и вставки из общего комплекта `native-undo.md` относятся к следующим тикетам и для №69 не нужны.
