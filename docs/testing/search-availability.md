# Доступность поиска без embeddings

Выполнить `npm run build`, установить `main.js`, `manifest.json`, `styles.css` в папку плагина тестового хранилища и перезагрузить Obsidian. Скопировать содержимое `docs/fixtures/search-availability/vault` в тестовое хранилище. Для ответов по папкам настроить модель диалога и достаточное контекстное окно.

1. Очистить embedding-модель и адрес её сервера. При выключенном поиске список режимов скрыт. Включить поиск кнопкой: список появляется с выбранным режимом «Папки», без предупреждения. Выключить поиск: список снова скрыт. Повторить включение через команду и меню панели.
2. Открыть настройки плагина обычным способом: Настройки → Obsidian AI Helper → Поиск. Проверить доступность адреса, API-ключа, выбора/ручного ввода embedding-модели и проверки подключения.
3. Без embeddings включить поиск и спросить: «Где хранить справочные материалы о методах работы?». Ответ опирается на описание «Знания»; embedding-запросов нет. Попытки выбрать «Заметки» или смешанный режим вызывают пояснение и сохраняют режим «Папки».
4. Без embeddings попробовать индексацию активной заметки, пункт контекстного меню заметки, индексацию хранилища и повтор обновлений. Проверить индексацию и смену хранения в настройках. Все действия блокируются до начала работы, с текстовым пояснением. Очистка индекса остаётся доступной.
5. Повторить с заполненной моделью и некорректным адресом: `ftp://server/v1`, `https://server/v1?key=значение`, `https://user:password@server/v1`. Ограничения те же.
6. Ввести корректный HTTP(S)-адрес и модель, не нажимая «Проверить embeddings». При включении поиска автоматически выбираются «Заметки»; смешанный режим и индексация доступны. Выбрать «Папки» или смешанный режим, выключить и снова включить поиск: опять выбраны «Заметки». При временно недоступном сервере показывается обычная ошибка подключения, возможность включать режим сохраняется.
7. При включённом поиске по заметкам набрать сообщение и удалить embedding-модель в настройках. Поиск выключается с пояснением, список скрывается; черновик сохраняется. При следующем включении автоматически выбраны «Папки». Повторить со смешанным режимом. Поиск по папкам при такой смене настроек остаётся включённым.
8. Повторить проверку текстового пояснения на английском языке, в светлой и тёмной темах. Предупреждение использует цвет темы и не содержит кнопок.

Автоматические проверки: `npm test` и `npm run build`. Навигацию, внешний вид и реальную работу сервера проверяет пользователь в Obsidian.
