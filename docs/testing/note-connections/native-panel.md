# #60: команда и жизненный цикл панели Obsidian

Узкая ручная проверка нужна для фактической передачи несохранённого текста редактором Obsidian и сохранения отдельной операции при скрытии нативной панели. Тестовый адаптер подтверждает код операции, но не поведение самого Obsidian. Отбор, ссылки, исключения, ответы модели, отмена, локализация и изоляция диалога проверяются автоматически в `test/note-connections.test.ts`; повторять их вручную не требуется.

Подготовка: установить зависимости проекта (`npm install`) и закрыть тестовое хранилище в Obsidian перед созданием или обновлением. Из корня репозитория выполнить:

```sh
python3 docs/testing/prepare_vault.py --source docs/testing/note-connections/notes --dest docs/testing/note-connections/native-panel-vault
```

Скрипт создаёт заметки об обучении, расписании повторений, карточках и работе над ошибками, выполняет `npm run build` и устанавливает `main.js`, `manifest.json`, `styles.css` в `.obsidian/plugins/<id из manifest.json>/`. При запуске из другой папки указывать абсолютные пути скрипта, исходной папки и назначения; корень проекта для сборки определяется автоматически. Без параметров скрипт выводит справку и пример запуска, не изменяя файлы. Для непустого назначения доступно меню: полная замена; замена с сохранением настроек и обновлением плагина; замена только контента без сборки; отмена. Варианты 1–3 удаляют прежний контент за пределами `.obsidian`.

Точный путь тестового хранилища: `docs/testing/note-connections/native-panel-vault/`. Открыть его в Obsidian, отключить Restricted mode, включить установленный плагин и настроить embedding-модель и модель диалога с известным окном контекста. Генератор не копирует настройки подключения из других хранилищ.

Проиндексировать хранилище. Открыть `Обучение.md`, дописать уникальную фразу и сразу выполнить команду «Найти связи для текущей заметки». В журнале запросов модель-сервера проверить наличие новой фразы в JSON исходной заметки. В панели должно быть название `Обучение.md`; после перехода в `Расписание.md` название исходной заметки остаётся прежним.

## Жизненный цикл панели — #66

Ручная проверка нужна только для нативного скрытия и уничтожения вкладки: адаптер тестов не воспроизводит эти действия Obsidian. Отмену запросов, занятость, очистку, изоляцию обычного диалога и поздние ответы уже проверяют автоматические тесты; повторять их вручную не нужно.

1. В настройках задать количество предложений связей `1`. Запустить поиск из `Обучение.md`. Выбрать карточку и добавить связь; нажать «Показать ещё», затем выбрать новую карточку. Если модель не находит достаточно полезных связей, проверить доступность всех тестовых заметок и повторить поиск.
2. Скрыть правую боковую панель штатной кнопкой Obsidian и открыть снова. Затем скрыть и открыть чат командой плагина или значком на ленте. Порции, отметка «Добавлено» и выбранная карточка сохраняются; предупреждение о сбросе не появляется.
3. Закрыть именно вкладку чата через её крестик или штатное меню закрытия вкладки. Появляется предупреждение о потере несохранённого выбора. Нажать «Отмена»: чат вновь открывается с прежними порциями, выбором и отметками добавления. Публичный API Obsidian не позволяет отменить уже начавшееся закрытие вкладки, поэтому отмена восстанавливает панель.
4. Снова закрыть вкладку и подтвердить «Закрыть панель». Открыть чат: поиска и выбора нет. Уже добавленная связь в `Обучение.md` остаётся. Закрытие вкладки без несохранённого выбора не требует подтверждения.

Поиск хранится только в памяти: перезапуск и выгрузка плагина сбрасывают его. Проверка не требует Computer Use и выполняется пользователем.

Восстановление: закрыть `docs/testing/note-connections/native-panel-vault/` в Obsidian, повторить указанную команду и выбрать режим 3 для восстановления заметок без изменения плагина и настроек либо режим 2 для восстановления заметок и обновления сборки с сохранением настроек. После открытия заново проиндексировать хранилище и очистить диалог.

Автоматические проверки генератора (во временных папках):

```sh
python3 -m unittest discover -s docs/testing -p 'test_prepare_vault.py' -v
```
