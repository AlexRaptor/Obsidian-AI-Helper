# #60: команда и жизненный цикл панели Obsidian

Узкая ручная проверка нужна для фактической передачи несохранённого текста редактором Obsidian и сохранения отдельной операции при скрытии нативной панели. Тестовый адаптер подтверждает код операции, но не поведение самого Obsidian. Отбор, ссылки, исключения, ответы модели, отмена, локализация и изоляция диалога проверяются автоматически в `test/note-connections.test.ts`; повторять их вручную не требуется.

Подготовка: установить зависимости проекта (`npm install`) и закрыть тестовое хранилище в Obsidian перед созданием или обновлением. Из корня репозитория выполнить:

```sh
python3 docs/testing/prepare_vault.py --source docs/testing/note-connections/notes --dest docs/testing/note-connections/native-panel-vault
```

Скрипт создаёт две заметки (`Обучение.md` и `Расписание.md`), выполняет `npm run build` и устанавливает `main.js`, `manifest.json`, `styles.css` в `.obsidian/plugins/<id из manifest.json>/`. При запуске из другой папки указывать абсолютные пути скрипта, исходной папки и назначения; корень проекта для сборки определяется автоматически. Без параметров скрипт выводит справку и пример запуска, не изменяя файлы. Для непустого назначения доступно меню: полная замена; замена с сохранением настроек и обновлением плагина; замена только контента без сборки; отмена. Варианты 1–3 удаляют прежний контент за пределами `.obsidian`.

Точный путь тестового хранилища: `docs/testing/note-connections/native-panel-vault/`. Открыть его в Obsidian, отключить Restricted mode, включить установленный плагин и настроить embedding-модель и модель диалога с известным окном контекста. Генератор не копирует настройки подключения из других хранилищ.

Проиндексировать хранилище. Открыть `Обучение.md`, дописать уникальную фразу и сразу выполнить команду «Найти связи для текущей заметки». В журнале запросов модель-сервера проверить наличие новой фразы в JSON исходной заметки. В панели должно быть название `Обучение.md`; после перехода в `Расписание.md` название исходной заметки остаётся прежним.

Скрыть и снова показать панель чата: операция или готовый результат сохраняется. При появлении предложения раскрыть фрагмент: заголовки, текст и сходство читаемы в узкой панели, ссылка открывает найденную заметку. Во время следующего поиска закрыть панель с уничтожением: поздний ответ не восстанавливает результат при новом открытии. Исходные файлы не изменяются плагином.

Восстановление: закрыть `docs/testing/note-connections/native-panel-vault/` в Obsidian, повторить указанную команду и выбрать режим 3 для восстановления заметок без изменения плагина и настроек либо режим 2 для восстановления заметок и обновления сборки с сохранением настроек. После открытия заново проиндексировать хранилище и очистить диалог.

Автоматические проверки генератора (во временных папках):

```sh
python3 -m unittest discover -s docs/testing -p 'test_prepare_vault.py' -v
```
