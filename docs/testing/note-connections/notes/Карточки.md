# Карточки для активного вспоминания

Разбейте изученное на вопросы с короткими ответами. На лицевой стороне карточки задайте вопрос, на обратной приведите проверяемый ответ и пример. Сначала отвечайте по памяти, затем открывайте оборот. Это превращает активное вспоминание в конкретное упражнение между повторениями.
