# #62: доставка меню нескольких папок в Obsidian

Нужна только узкая пользовательская проверка: публичные типы Obsidian содержат `Workspace.on("files-menu", ...)`, но автоматический адаптер не подтверждает, что проводник действительно доставляет это событие для выбранных папок. Фильтрация области, пересечения, исключения, смешанный выбор, запросы, карточки и запись проверены автоматически; повторять эти сценарии вручную не требуется. Computer Use не применяется.

Из корня репозитория, после установки зависимостей, выполнить:

```sh
python3 docs/testing/prepare_vault.py --source docs/testing/note-connections/folder-scope/notes --dest docs/testing/note-connections/folder-scope/multiple-folders-vault
```

Точное хранилище: `docs/testing/note-connections/folder-scope/multiple-folders-vault/`. Перед обновлением закрыть его в Obsidian. Общий генератор собирает плагин и устанавливает файлы в `.obsidian/plugins/<id из manifest.json>/`; настройки подключений не копируются. При непустом назначении режим 1 заменяет всё, режим 2 сохраняет `.obsidian` и обновляет плагин, режим 3 восстанавливает только контент без сборки, режим 4 отменяет. Режимы 1–3 удаляют прежний контент за пределами `.obsidian`.

1. Открыть это хранилище в Obsidian, отключить Restricted mode, включить Obsidian AI Helper. Настроить embedding-модель и модель диалога, задать известное окно контекста. Проиндексировать хранилище.
2. Открыть `Исходная/Обучение.md`. В проводнике выделить папки `Примеры` и `Дополнения` с Ctrl/Cmd. Открыть контекстное меню выделения. Должно появиться действие «Найти связи для текущей заметки в выбранных папках».
3. Запустить действие. В чате должен появиться результат с заголовком `Исходная/Обучение.md` либо понятное состояние операции, например ошибка настройки модели. Уже появление результата подтверждает доставку события и вызов обработчика. При успешном ответе модели предложения могут относиться к двум выбранным папкам и вложенной папке; отсутствие предложений само по себе не означает сбой доставки события.

Если действие не появилось или не открыло результат, сообщить версию Obsidian, ОС, способ выделения и источник контекстного меню. Не использовать частные интерфейсы проводника для обхода проблемы.

Для восстановления закрыть указанное тестовое хранилище и повторить ту же команду: режим 3 восстанавливает заметки с сохранением сборки и настроек, режим 2 также обновляет сборку. После открытия проиндексировать хранилище заново. Отчёт о других автоматизированных сценариях не требуется.
