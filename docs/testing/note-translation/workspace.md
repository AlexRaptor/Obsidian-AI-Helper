# Открытие в реальном рабочем пространстве

Хранилище: `docs/testing/note-translation/translation-vault/`. Подготовка и полное восстановление — по README в этой папке; при повторе использовать указанный там новый путь хранилища. Проверка нужна потому, что помощник Obsidian не создаёт настоящие области приложения и не переключает режим редактора.

1. В настройках перевода указать русский язык, папку оригинала, исходное имя с суффиксом ` — ru`, включить открытие рядом.
2. Открыть `Статьи/How to take notes.md` в режиме редактирования. В отдельной области открыть `Рабочее пространство.md`.
3. Запустить «Перевести текущую заметку» из исходной статьи и переключиться в область с `Рабочее пространство.md` до завершения. Дождаться сохранения.
4. Проверить: оригинал слева, перевод справа с вертикальным разделителем, оба открыты в режиме чтения, перевод активен. Область с `Рабочее пространство.md` сохранена. Ссылка на оригинал располагается после свойств перед содержимым.
5. Отключить открытие рядом, изменить суффикс на ` — ru solo`, снова запустить перевод из оригинала. Проверить: до завершения переключиться в область с `Рабочее пространство.md`. Новый перевод открыт в этой текущей области в режиме чтения, новая пара областей не создавалась.
6. Для проверки закрытой исходной области включить открытие рядом, изменить суффикс на ` — ru new`, запустить перевод из оригинала и закрыть именно исходную область до завершения. Проверить: создана новая пара оригинал/перевод в режиме чтения, остальные области сохранены.

Шаг 6 имеет смысл только если модель отвечает достаточно долго. Если результат сохранился до закрытия области, повторить этот шаг с новым суффиксом; это не ошибка функции. Автоматические проверки независимо покрывают этот порядок событий детерминированно.
