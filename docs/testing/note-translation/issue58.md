# #58: качество перевода на используемой модели

Нужна только ручная оценка качества и соблюдения формата реальной моделью:
подменённая сеть проверяет протокол и сборку, но не доказывает согласованность
переведённых фраз. Проверку выполняет пользователь. Агент модель-сервер не
вызывал; реальных результатов пока нет.

## Подготовка и восстановление

Закрыть тестовое хранилище и выполнить из корня репозитория:

```sh
python3 docs/testing/note-translation/prepare_vault.py --dest docs/testing/note-translation/translation-vault
```

При существующей папке выбрать режим 2 для обновления плагина с сохранением
настроек или режим 1 для полного сброса. Генератор уже содержит полную
`Статьи/How to take notes.md`, `Справка/Метод.md` и `Вложения/Схема.svg`.
Копия оригинала для сравнения: [issue58-source.md](issue58-source.md).
Повторный запуск генератора восстанавливает начальное состояние; перед ним
сохранить результаты вне тестового хранилища. Для пробелов в якоре статьи
используется та же исходная ссылка `(#A practical method)`.

Открыть `docs/testing/note-translation/translation-vault` в Obsidian,
включить community plugins, настроить собственное подключение и модель,
язык перевода «Русский», суффикс « — ru», исходное имя с суффиксом.
Секреты и полный запрос в отчёт не копировать.

## Запуски

1. Перевести `Статьи/How to take notes.md` командой. Проверить весь перевод:
   все предложения и подписи есть; русский абзац сохранён; три ссылки
   работают, самоссылка ведёт к переведённому разделу; выделение, таблица,
   callout, сноска и `^stable-block` целы; формула и код дословны; встраивание
   не раскрыто. Служебных маркеров нет. Оценить связность всей статьи.
2. Удалить только созданный перевод и повторить через контекстное меню.
   Ещё раз удалить результат и повторить командой (всего минимум три запуска).
   При ошибке записать вид нарушения и ID из прогресса; проверить явное
   продолжение или завершение. Не скрывать ошибки из итогового отчёта.
3. В отдельной заметке в том же хранилище проверить каждую фразу ниже,
   минимум три независимых запуска. Оценить грамматику, согласование и
   отсутствие потери смысла рядом с выделением/ссылками/кодом/формулой:

```markdown
Read the **very *important*** [guide](https://example.org) before continuing.

The [results](https://example.org) **of the latest experiment** are reliable.

Keep `cache.get(key)` and $E = mc^2$ unchanged while explaining their role.

Это русский текст, а **this useful [reference](https://example.org)** требует перевода.
```

Сравнить связность с переводом тех же фраз без выделения и ссылок в отдельной
заметке: заметное ухудшение на форматированном варианте фиксировать как
ограничение, а не считать успешный JSON доказательством качества.
