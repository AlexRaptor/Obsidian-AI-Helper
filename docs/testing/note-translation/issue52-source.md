# Сложная статья

Обычный текст с двумя упоминаниями одной сноски[^источник] и повтором[^источник].

| Название | Значение | Пустая ячейка |
| :--- | ---: | :---: |
| **Первый пункт** | Текст с `const secret = 1` | |
| Второй пункт[^источник] | Путь \| продолжение | |

> [!tip]- **Мой совет**
> Содержимое сворачиваемого блока.
>
> | Имя | Описание |
> | --- | --- |
> | Пункт | Значение |
>
> > [!note]+ Вложенное примечание
> > - **Важный пункт**
> > - Обычный пункт
> >
> > ```markdown
> > > [!warning] Это код, он не переводится
> > ```

> [!note]
> У этого блока нет пользовательского заголовка.

[^источник]: Первая строка определения с **выделением**.
    Продолжение определения с `защищённым кодом`.

    Второй абзац определения.

Обычный текст после определения. Формула $E = mc^2$ сохраняется.
