# Как делать конспекты

Хороший конспект сохраняет контекст. Полезный перевод сохраняет смысл автора и структуру документа.

Этот абзац уже написан на русском языке и должен остаться без изменений.

Прочитайте [следующий раздел](#Практический%20метод), [связанную заметку](../Справка/Метод.md) и [[../Справка/Метод.md|полезное справочное]].

## Практический метод

1. Прочитайте статью и определите её главный аргумент.
2. Записывайте **важные идеи**, *примеры* и ~~устаревшие советы~~.
   - Сохраняйте достаточно контекста для будущего чтения.
   - [ ] Пересмотрите результат завтра.

> [!tip] Полезная привычка
> Предпочтительнее несколько ясных предложений, чем длинный список несвязанных слов.

| Шаг | Цель |
| --- | --- |
| Прочитать | Понять аргумент |
| Записать | Сохранить полезные детали |

Не меняйте выражение $E = mc^2$ и команду `npm run build`.

```typescript
// Этот комментарий сохраняется дословно.
const original = "Do not translate this string";
```
