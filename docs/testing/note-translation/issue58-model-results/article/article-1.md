# Как делать конспекты

Хороший конспект сохраняет контекст. Полезный перевод сохраняет смысл автора и структуру документа.

Этот абзац уже написан на русском языке и должен остаться без изменений.

Прочитайте [следующий раздел](#Практический%20метод), [связанное примечание](../Справка/Метод.md) и [[../Справка/Метод.md|полезный справочный материал]].

## Практический метод

1. Прочитайте статью и определите её главный аргумент.
2. Записывайте **важные идеи**, *примеры* и ~~устаревшие советы~~.
   - Сохраняйте достаточно контекста для будущего прочтения.
   - [ ] Просмотрите результат завтра.

> [!tip] Полезная привычка
> Предпочитайте несколько понятных предложений длинному списку несвязанных слов.

| Шаг | Цель |
| --- | --- |
| Чтение | Понять аргумент |
| Запись | Сохранить полезные детали |

Оставьте выражение $E = mc^2$ и команду `npm run build` без изменений.

```typescript
// Этот комментарий сохраняется дословно.
const original = "Do not translate this string";
```
