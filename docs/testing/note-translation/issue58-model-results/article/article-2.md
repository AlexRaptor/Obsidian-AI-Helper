# Как делать записи

Хорошие записи сохраняют контекст. Полезный перевод сохраняет смысл автора и структуру документа.

Этот абзац уже написан на русском языке и должен остаться без изменений.

Прочитайте [следующий раздел](#Практический%20метод), [связанную заметку](../Справка/Метод.md) и [[../Справка/Метод.md|полезный источник]].

## Практический метод

1. Прочитайте статью и определите её главный аргумент.
2. Записывайте **важные идеи**, *примеры* и ~~устаревшие советы~~.
   - Сохраняйте достаточный контекст для будущего чтения.
   - [ ] Рассмотрите результат завтра.

> [!tip] Полезная привычка
> Предпочитайте несколько ясных предложений длинному списку несвязанных слов.

| Шаг | Цель |
| --- | --- |
| Чтение | Понимание аргумента |
| Запись | Сохранение полезных деталей |

Оставьте выражение $E = mc^2$ и команду `npm run build` без изменений.

```typescript
// Этот комментарий сохраняется дословно.
const original = "Do not translate this string";
```
