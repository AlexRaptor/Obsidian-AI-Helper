# Тикет #30: рекомендации для открытой заметки

Ручная проверка подготовлена, но агентом не выполнялась. Выполняет пользователь в настоящем Obsidian.

## Создание и восстановление хранилища

Из корня `/Users/selivanov/code/Obsidian-AI-Helper`:

```sh
npm run build
node docs/fixtures/issue30-note-review/create-vault.mjs docs/fixtures/issue30-note-review/vault
```

Готовое отдельное хранилище: `/Users/selivanov/code/Obsidian-AI-Helper/docs/fixtures/issue30-note-review/vault`.
Все исходные тексты и настройки приведены в `docs/fixtures/issue30-note-review/create-vault.mjs`. Генератор отказывается перезаписывать существующую папку. Для восстановления закрыть тестовое хранилище и создать новый набор той же командой с новым назначением, например `docs/fixtures/issue30-note-review/vault-reset`. Рабочее хранилище не использовать.

Открыть готовую папку как хранилище Obsidian. Отключить Restricted mode и включить Obsidian AI Helper в Community plugins; перезагрузить Obsidian. Плагин уже скопирован генератором в `.obsidian/plugins/<id из manifest.json>/`.

В настройках плагина указать адрес собственного OpenAI-совместимого модель-сервера, ключ при необходимости и доступную модель диалога, которая умеет следовать инструкции о JSON. Достаточно одной модели диалога; embedding-модель не нужна, поля её подключения оставить пустыми. Окно контекста 32768 подходит для этого небольшого набора, если модель действительно поддерживает его; при меньшем окне указать реальный размер. Язык плагина русский; имя описания `_folder.md`; исключена папка `Личное`; автообновление заметок выключено. Обычный индекс не строить. Содержимое тестовых заметок и описаний будет отправлено выбранному модель-серверу.

## Сценарии

1. **Нативная вкладка и текущий редактор.** Открыть чат справа. В основном редакторе открыть `Личное/План.md`. В режиме чтения из палитры команд выполнить «Предложить папку для текущей заметки». Ожидание: справа отдельная вкладка «Разбор заметок», чат сохранён, основной редактор доступен; в панели название, исходный путь и до трёх рекомендаций с объяснениями и полными путями. Полного текста и второго редактора нет. Повтор команды использует ту же вкладку. Переключить заметку в режим редактирования и повторить: команда также доступна, анализирует текущий текст. Заметка не перемещается и не добавляется командой в обычный индекс.
2. **Родители, исключения и два языка.** Для `Личное/План.md` сравнить объяснения с `_folder.md`, `Знания/_folder.md`, `Знания/Проект/_folder.md` (английский) и `Личное/_folder.md` (русский). Ожидание: модель учитывает назначение и статус проекта; при рекомендации `Знания/Проект` объясняет явное исключение из родительского запрета. `Личное` допустима, хотя исключена из индекса. `Пустая` и `Знания/Без описания` не предлагаются. Ссылки открывают существующее описание, а не выдуманный источник. Включить основной плагин Obsidian «Предпросмотр страниц» (Page preview); в его настройках проверить источник «Разбор заметок». Навести на ссылку описания с Cmd/Ctrl: появляется нативное превью. При отключении требования клавиши в настройках источника превью появляется при обычном наведении. Изменившееся описание не показывается как проверенное превью. Оценку правдоподобия фиксировать отдельно: качество зависит от модели.
3. **Текущий текст и устаревание.** Во время анализа изменить тело и свойство `статус` в основном редакторе. Ожидание: отметка об устаревании; автоматического нового запроса нет. После ответа изменить заголовок файла через Obsidian: отметка сохраняется, путь и название обновляются. Нажать «Обновить рекомендации»: анализируется новая версия. Превратить заметку в справку о методе, убрать проектные действия, поставить `назначение: справка` и снова обновить; проверить соответствие новых объяснений содержимому. Изменить использованное описание: старую ссылку панель не открывает, требуется обновление.
4. **Нормальные альтернативные исходы.** Открыть `Знания/Обзор.md`, затем `Inbox/Ссылки.md` и `Inbox/Нет папки.md`; каждый раз выполнить команду. Ожидание: допустимы «оставить в текущей папке», «недостаточно содержания» и «подходящей папки нет». Для заметки из одних ссылок не должны читаться связанные заметки и вложения. Ответы без кандидатов не содержат выдуманных ссылок; процентов уверенности нет.
5. **Остановка, ошибка, повтор.** Запустить анализ и нажать «Остановить анализ» до ответа. Во время запроса «Анализ заметки…» пульсирует так же, как «Думаю…» в чате; после остановки анимация исчезает. При включённом уменьшении движения в системных настройках анимация отключена. Дождаться позднего ответа модель-сервера: он не появляется. Повторить кнопкой обновления. Затем временно указать недоступный адрес модель-сервера: понятная ошибка, панель остаётся доступной. Вернуть адрес и повторить. Закрыть вкладку во время запроса: поздний результат не открывает её снова.
6. **Контекст без усечения.** Установить окно контекста `1024`, обновить рекомендации. Ожидание: остановка с сообщением о превышении контекста без усечения. Вернуть поддерживаемый размер, повторить. Набор описаний сохраняется полностью.
7. **Локализация, имя, узкий экран.** Переключить язык плагина на English: открытая панель показывает Note review, Refresh recommendations и Stop analysis. Обновить: объяснения запрашиваются по-английски, исходные русские и английские описания не изменяются. Для проверки имени задать `about.md` с оставлением существующих файлов: участвует только `Другие описания/about.md`. Вернуть `_folder.md`. Сузить правую панель: длинные пути переносятся, кнопки доступны, прокрутка работает с обычной темой и тёмной темой Obsidian.

## Фиксация результатов

Для каждого сценария записать фактический результат и версию Obsidian, модель-сервер, модель диалога и размер контекста. Подготовку набора и автоматические тесты не считать прохождением ручных сценариев. Для восстановления исходных текстов воспользоваться новым назначением генератора, как описано выше.
