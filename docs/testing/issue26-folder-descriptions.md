## Использованный набор

Фактически создано и открыто отдельное хранилище `/tmp/issue26-folder-vault` командой:

```sh
npm run build
node test/fixtures/manual-folder-descriptions/create-vault.mjs /tmp/issue26-folder-vault
```

Генератор после прогона перенесён в `docs/fixtures/issue26-folder-descriptions/create-vault.mjs`; в нём находятся точные исходные файлы и содержимое. Чистое хранилище для проверки пользователем создано в `docs/fixtures/issue26-folder-descriptions/vault`. Приведённая выше команда фиксирует исторический запуск до переноса. Инструкция запуска, настройки Obsidian/плагина, ожидаемые результаты и восстановление приведены в `docs/testing/issue26-manual-test-cases.md`. Генератор не перезаписывает существующий каталог; для восстановления исходных данных следует закрыть тестовое хранилище и выполнить генератор с новым путём. Рабочее хранилище пользователя не изменялось.

Исходные настройки: язык плагина `ru`, имя `_folder.md`, `Private` исключена, автообновление выключено, серверы и модели не настроены, обычный индекс не построен. Для данного тестового хранилища пользователь подтвердил включение сторонних плагинов. После исправлений ревью окончательные `main.js` и `styles.css` повторно скопированы в папку плагина; Obsidian перезагружен.
