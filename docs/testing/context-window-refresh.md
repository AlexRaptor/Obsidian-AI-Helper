# Обновление окна контекста

1. Собрать плагин командой `npm run build`, скопировать `main.js`, `manifest.json` и `styles.css` в папку плагина тестового хранилища и перезагрузить Obsidian.
2. Выбрать модель на сервере, поддерживающем определение текущего окна контекста. Оставить поле «Окно контекста» пустым.
3. Отправить сообщение. Перезапустить выбранную модель с другим размером окна, сохранив её идентификатор и адрес сервера. Отправить следующее сообщение: статистика должна учитывать новый размер окна.
4. При малом окне запустить рекомендацию папки для заметки, полный запрос которой превышает лимит. Увеличить окно на сервере и повторить рекомендацию: запрос должен пройти без повторного открытия настроек. Уменьшить окно и повторить: проверка бюджета должна учитывать меньший лимит.
5. Ввести размер окна вручную. Повторить отправку сообщения и рекомендацию: используется ручной лимит, без обновления окна с сервера при этих действиях.
6. Остановить отправку сообщения или рекомендацию, пока сервер определяет окно: поздний результат определения не должен запускать ответ модели.
