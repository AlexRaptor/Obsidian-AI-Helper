# Пауза и восстановление индекса (#19)

Автоматические проверки используют публичный модуль поиска по заметкам, ввод/кнопки чата и подменяемый HTTP-транспорт. Они проверяют сохранённую паузу, восстановление новым экземпляром с тем же IndexedDB, изменения во время остановки, недоступный сервер без фоновых повторов, запуск плагина с разными настройками автоматизации, покрытие, локализацию, повторные нажатия и отклонение позднего результата после выгрузки.

Финальные автоматические результаты: `npm test` — 346 тестов в 28 файлах проходят; `npm run build` (проверка типов и производственная сборка) проходит. Ревью стандартов и соответствия тикету завершено без оставшихся замечаний.

Пользователь подтвердил успешное прохождение ручных проверок в настоящем Obsidian/LM Studio. Проверки выполнены отдельно от автоматических; ниже сохранён сценарий для повторной проверки.

1. Собрать плагин (`npm run build`), скопировать `main.js`, `manifest.json`, `styles.css` в `.obsidian/plugins/<manifest id>/` тестового хранилища. Использовать заметки из `test/fixtures/manual-vault-index/vault`, дополнить их пустой Markdown-заметкой и несколькими длинными заметками. Настроить embedding-модель, исключить `Private`, включить автоматическое обновление.
2. До первого запуска включить поиск: в шапке должна быть кнопка явной первой индексации. Создание и правки заметок до её нажатия не вызывают embedding-запросов. Запустить индексирование. Проверить полосу покрытия и подпись `N% - готово / всего`; знаменатель включает только разрешённые Markdown-заметки, пустая заметка учитывается без embedding-запроса. Во время обработки чат остаётся доступным.
3. После нескольких завершённых заметок нажать «Приостановить индексацию». Новые embedding-запросы не начинаются, поздний ответ отменённой заметки не принимается. В шапке видны сохранённое покрытие, пауза и кнопка продолжения. Несколько раз изменить ожидающую заметку, создать новую, удалить другую, переименовать заметку и изменить исключения. Проверить пересчёт покрытия и отсутствие новых запросов.
4. Полностью закрыть Obsidian. Во время остановки изменить одну завершённую заметку и одну ожидающую, удалить заметку, переместить другую в исключённую папку. Открыть Obsidian: ручная пауза сохраняется, покрытие соответствует текущему хранилищу, автоматического продолжения нет даже после выключения/включения поиска. Нажать «Продолжить индексацию» несколько раз. По журналу LM Studio подтвердить одну операцию, обработку только последних версий недостающих/изменённых заметок и отсутствие повторной обработки готовых неизменённых заметок. Удалённые и исключённые заметки не появляются среди источников.
5. Остановить LM Studio после частичного завершения индекса. Дождаться явной ошибки/ожидания сервера. Сделать несколько правок и создать заметку. Запустить LM Studio: без действий пользователя новых запросов нет, периодических проверок нет. Нажать «Повторить»; обработать только очередь. Повторить через выключение и включение поиска при включённом автоматическом обновлении.
6. Снова выключить LM Studio, накопить изменения и полностью перезапустить Obsidian. При включённой автоматизации и без ручной паузы допускается одна попытка возобновления после загрузки, затем видна ошибка/ожидание сервера. Новые правки и последующий запуск LM Studio не вызывают самопроизвольных повторов. Проверить ручной повтор.
7. Выключить автоматическое обновление, накопить изменения, перезапустить Obsidian и выключить/включить поиск: обработки нет. Ручное продолжение обрабатывает очередь. Повторить с сохранённой ручной паузой и включённой автоматизацией: снять её может только явное продолжение.
8. Сменить embedding-модель или подключение (в том числе при закрытом плагине). Старый индекс не возобновляется; интерфейс требует построить совместимый индекс. Выключить поиск и убедиться, что обычный диалог с доступной моделью диалога работает.
9. Во время обработки выгрузить плагин. В журнале сервера не должно быть новых фоновых запросов; поздний результат не восстанавливает источник. Снова загрузить плагин: сохранённая завершённая часть остаётся, очередь сверяется с хранилищем.
10. Проверить EN/RU, смену языка в открытом чате, подписи полосы и кнопок для вспомогательных технологий, управление с клавиатуры. Выключение поиска скрывает весь блок покрытия; повторное включение восстанавливает актуальный блок.

Пауза и очередь хранятся локально в IndexedDB рядом с производным индексом. Автоматические повторы по таймеру и периодические проверки доступности модель-сервера не используются.
