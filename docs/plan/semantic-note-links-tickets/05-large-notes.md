## Parent

#59 — Поиск смысловых связей для текущей заметки.

## What to build

Пользователь получает полезные предложения и для больших заметок: анализ использует материал из разных частей исходной заметки и релевантные фрагменты кандидатов, явно сообщает об ограничении и не обрезает текст незаметно.

## Acceptance criteria

- [ ] Вместо исходного отказа для большого текста применяется анализ по фрагментам. Для исходной заметки материал отбирается из разных частей, а не только из начала; для кандидата — по предполагаемой связи.

- [ ] Фрагменты сохраняют заголовки и достаточный окружающий контекст; передаваемый материал позволяет проверять объяснение на содержимом обеих заметок.

- [ ] Корректные блоки прежних связей не становятся материалом анализа ни в исходной заметке, ни в кандидатах; их ссылки продолжают исключать дубли.

- [ ] Пользователь явно видит, что анализ выполнен по фрагментам; UI не обещает полноты прочтения заметки или обнаружения всех связей.

- [ ] Бюджет модели учитывает служебные инструкции, материал заметок и резерв ответа. Если даже подготовленный материал не помещается, запрос останавливается с объяснением, без скрытого обрезания или автоматической подмены модели.

- [ ] Раскрываемый фрагмент и его числовое сходство соответствуют реальному материалу карточки; полезность связи по-прежнему выражена объяснением, а не порогом сходства.

- [ ] Автоматические сценарии содержат важное пересечение в конце большой русскоязычной заметки, неоднородные разделы, большие заметки-кандидаты и недостаточный бюджет. Проверяются отправленный материал, уведомление, результат и отсутствие лишних запросов при отказе.

- [ ] Для небольших заметок сохраняется существующий результат поиска; новый подбор материала не меняет контракт обычного поиска по заметкам.

- [ ] Новые действия и состояния локализованы на русский и английский, используют нативные компоненты и семантические цвета активной темы Obsidian.

- [ ] Приёмка проверяет внешнее поведение через команду или меню и элементы чата, запросы к модель-серверу и результат в заметках; основная логика не подменена. Тестовые данные преимущественно русскоязычные. Пройдены соответствующие автоматические тесты и производственная сборка с проверкой типов.
