## Parent

#59 — Поиск смысловых связей для текущей заметки.

## What to build

Пользователь выбирает предложения в чате и явно добавляет ссылки с объяснениями в конец исходной заметки. Повторные добавления дополняют только конечный блок, сохраняют ручные правки и не создают дублей.

## Acceptance criteria

- [ ] Карточки позволяют выбрать или отклонить предложение; «Добавить выбранные связи» записывает только выбранные ссылки и объяснения. Фрагменты и числовые показатели в заметку не попадают, другие заметки не изменяются.

- [ ] Формат — обычный Markdown-список в блоке с однозначными HTML-маркерами. Используется общий контракт с анализом, соответствующий ADR-0005. Маркеры одинаковы для языков; заголовок нового блока локализуется, существующий сохраняется.

- [ ] Дополняется только корректный блок, после закрывающего маркера которого есть лишь пробельные символы. Если блок перемещён или ниже появился текст, старый сохраняется и создаётся новый в конце.

- [ ] Прежние строки, объяснения и ручные правки сохраняются. Повреждённые, вложенные или неоднозначные границы вызывают отказ с объяснением и сохранением выбора.

- [ ] Перед записью повторно проверяются актуальный текст, существующие ссылки и версии найденных заметок. Исходный текст не подменяется устаревшим содержимым; при конфликте запись не выполняется.

- [ ] Постороннее изменение исходного содержимого блокирует запись до нового поиска, сохраняя результаты для просмотра. Удалённая исходная заметка не воссоздаётся; содержимое другого открытого редактора не используется вместо неё.

- [ ] Защита актуальности обязательна уже в этой задаче. Пока расширенная поддержка перемещений и частичных пропусков не реализована, такие изменения допускается консервативно отклонять с объяснением; устаревшие данные не записываются.

- [ ] Повторное нажатие блокируется на время записи. Ошибка записи не ставит ложную пометку успеха; повтор заново проверяет текст и ссылки и не создаёт дублей.

- [ ] Успешно добавленные предложения отмечаются «Добавлено» и исключаются из выбора, остальные остаются доступными. Итог содержит число добавленных и причины пропусков.

- [ ] Допускаются несколько добавлений в одном поиске: собственная успешная запись обновляет ожидаемую версию исходного текста и не считается посторонним изменением. Отказы не сохраняются между отдельными поисками.

- [ ] Несохранённый выбор не теряется молча при замене поиска, очистке или уничтожении панели: базовая защита потери выбора обязательна сразу; расширенные сочетания с порциями проверяются отдельной задачей.

- [ ] Проверки через пользовательские действия подтверждают точный Markdown-результат, формы ссылок, блоки после ручного редактирования, конфликт редактора и сохранённого текста, ошибки записи, повтор и неизменность других заметок. Для подтверждения синхронизации настоящего редактора при реализации подготовлена узкая ручная проверка, поскольку тестовый адаптер Obsidian её не гарантирует.

- [ ] Новые действия и состояния локализованы на русский и английский, используют нативные компоненты и семантические цвета активной темы Obsidian.

- [ ] Приёмка проверяет внешнее поведение через команду или меню и элементы чата, запросы к модель-серверу и результат в заметках; основная логика не подменена. Тестовые данные преимущественно русскоязычные. Пройдены соответствующие автоматические тесты и производственная сборка с проверкой типов.
