## Parent

#59 — Поиск смысловых связей для текущей заметки.

## What to build

Пользователь запускает поиск для текущей заметки из контекстного меню одной или нескольких выбранных папок. Предложения приходят только из объединённой допустимой области этих папок и их подпапок.

## Acceptance criteria

- [ ] Действие одной папки и действие множественного выбора зарегистрированы через публичные API Obsidian; частные интерфейсы проводника не используются.

- [ ] Выбранные папки определяют кандидатов, а не исходные заметки. Текущая заметка остаётся единственной исходной, её название показано в чате.

- [ ] Области рекурсивны, пересекающиеся поддеревья объединяются без повторного показа или обработки одной заметки.

- [ ] Существующие исключения индексации действуют при любом запуске, включая явный выбор исключённой папки и исключённые подпапки выбранного родителя. Отдельного временного индекса нет.

- [ ] При смешанном выборе файлов и папок действие не показывается. Если допустимая область пуста, причина показывается до обращения к модели.

- [ ] Поиск не читает и не передаёт модель-серверу кандидатов вне области; выбор папки не требует нахождения исходной заметки внутри неё.

- [ ] Команда поиска по всему хранилищу продолжает работать. Неполное покрытие выбранной области не выдаётся за исчерпывающий поиск.

- [ ] Автоматические проверки вызывают реальные зарегистрированные обработчики меню и подтверждают область по запросам и карточкам; включены вложенные, пересекающиеся, исключённые папки и смешанный выбор.

- [ ] При реализации подготовлены точные инструкции и данные для узкой пользовательской проверки меню нескольких папок в Obsidian: публичные типы подтверждают наличие API, но не фактическую доставку события проводником. Материалы сгруппированы в папке ручной проверки функции; если нужен генератор, он на Python с --dest и четырьмя стандартными режимами. Computer Use без отдельного запроса не применяется.

- [ ] Новые действия и состояния локализованы на русский и английский, используют нативные компоненты и семантические цвета активной темы Obsidian.

- [ ] Приёмка проверяет внешнее поведение через команду или меню и элементы чата, запросы к модель-серверу и результат в заметках; основная логика не подменена. Тестовые данные преимущественно русскоязычные. Пройдены соответствующие автоматические тесты и производственная сборка с проверкой типов.
