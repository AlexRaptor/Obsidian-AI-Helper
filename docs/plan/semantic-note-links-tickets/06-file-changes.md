## Parent

#59 — Поиск смысловых связей для текущей заметки.

## What to build

Пользователь продолжает работу с предложениями после переименований и перемещений неизменных заметок. Устаревшие или удалённые кандидаты пропускаются с объяснением, а изменения исходного содержания требуют нового поиска без опасной записи.

## Acceptance criteria

- [ ] Операция отслеживает ту же исходную заметку при переименовании и перемещении без изменения содержимого. Переключение активной заметки не меняет цель записи; удаление блокирует добавление и не создаёт файл заново.

- [ ] После посторонней правки исходного содержимого результаты и выбор доступны для просмотра, но запись целиком заблокирована до нового поиска. Новый поиск начинается без отметок с предупреждением о потере выбора.

- [ ] Собственное добавление связей обновляет ожидаемый текст и позволяет добавлять оставшиеся предложения без повторного анализа.

- [ ] Неизменные кандидаты после переименования или перемещения получают актуальные ссылки. Удалённые кандидаты и кандидаты с изменённым содержимым пропускаются с причиной, остальные выбранные сохраняются.

- [ ] Версия объяснения привязана к содержимому кандидата при анализе. Изменение в ходе запроса или после показа не подменяет эту основу молча.

- [ ] Существующие ссылки повторно проверяются перед записью. Посторонняя правка исходной заметки имеет приоритет и блокирует всю запись; частичный пропуск кандидатов не обходит эту проверку.

- [ ] Проверка и запись сохраняют параллельные правки редактора и хранилища. Ошибка записи оставляет возможность безопасного повтора без дублей и без ложных пометок успеха.

- [ ] Автоматически проверены переименование, перемещение, удаление и изменение обеих сторон, замена файла по прежнему пути, события во время запроса и между проверкой и записью, смешанный набор актуальных и устаревших кандидатов.

- [ ] Проверки используют актуальный текст редактора и не полагаются на синхронное обновление кэша метаданных. Требуемая узкая проверка реальной синхронизации редактора дополняет материалы безопасного сохранения, не дублируя автоматическую приёмку.

- [ ] Новые действия и состояния локализованы на русский и английский, используют нативные компоненты и семантические цвета активной темы Obsidian.

- [ ] Приёмка проверяет внешнее поведение через команду или меню и элементы чата, запросы к модель-серверу и результат в заметках; основная логика не подменена. Тестовые данные преимущественно русскоязычные. Пройдены соответствующие автоматические тесты и производственная сборка с проверкой типов.
