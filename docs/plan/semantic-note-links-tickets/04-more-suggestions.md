## Parent

#59 — Поиск смысловых связей для текущей заметки.

## What to build

Пользователь задаёт размер порции, получает дополнительные полезные предложения кнопкой «Показать ещё» и сохраняет накопленный выбор. Ошибка или отмена следующей порции не уничтожает готовые результаты.

## Acceptance criteria

- [ ] Настройка «Количество предложений связей» принимает только целые значения от 1 до 20; значение по умолчанию 5. Настройка сохраняется и валидируется, размер фиксируется при запуске и не меняется от последующих правок настройки.

- [ ] Первая и следующие порции собираются из зафиксированного при запуске набора в согласованном порядке до заполнения полезными предложениями или исчерпания кандидатов. Повторного полного поиска по хранилищу при нажатии нет.

- [ ] Одна целевая заметка показывается не более одного раза за поиск, включая уже добавленные, выбранные и отклонённые карточки. Выбор прежних порций и пометки «Добавлено» сохраняются.

- [ ] Если полезных связей меньше размера порции, показывается доступное количество. Исчерпание обозначается текстом «Больше предложений в этом поиске нет», без обещания полноты по хранилищу.

- [ ] Порция становится видимой только после завершения. При ошибке или отмене незавершённая порция не публикуется, ранее показанные карточки и выбор сохраняются.

- [ ] Повтор обработки незавершённой порции не теряет кандидатов, не повторяет карточки и не сбрасывает выбор. Поздний ответ отменённой попытки не завершает новую.

- [ ] Во время получения порции доступны понятное состояние и отмена; повторные конкурентные запросы порции отклоняются. Между порциями можно общаться в чате.

- [ ] Добавление выбранного после нескольких порций сохраняет ссылки из всех отмеченных карточек по правилам безопасной записи; собственное добавление не мешает продолжению поиска.

- [ ] Автоматически проверены границы настройки, её изменение в ходе поиска, отказанные кандидаты между полезными, неполная последняя порция, исчерпание, ошибка, отмена, повтор, поздний ответ и добавление из нескольких порций.

- [ ] Новые действия и состояния локализованы на русский и английский, используют нативные компоненты и семантические цвета активной темы Obsidian.

- [ ] Приёмка проверяет внешнее поведение через команду или меню и элементы чата, запросы к модель-серверу и результат в заметках; основная логика не подменена. Тестовые данные преимущественно русскоязычные. Пройдены соответствующие автоматические тесты и производственная сборка с проверкой типов.
