## Проверки и тестовые данные

В каждой задаче требуется подготовить и фактически создать отдельное тестовое хранилище с воспроизводимыми данными для её ручных сценариев. Можно переиспользовать общий набор фикстур с дополнениями.

Каждый документ ручного тестирования должен описывать создание хранилища, получение конкретных файлов и их содержимого, необходимые настройки, ожидаемые результаты и восстановление исходного состояния. Отчёт должен указывать использованные данные и реально выполненные проверки.

Требования к набору данных и проверкам собраны в [плане ручной проверки](folder-descriptions-manual-verification.md). Реализация функции и сами ручные проверки ещё не выполнялись.
