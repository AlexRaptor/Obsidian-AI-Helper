# Виртуализация длинных диалогов

Дата: 2026-10-10. Источник: сессия grill-with-docs. Термины — из `CONTEXT.md`.
Статус: обсуждение; итоговый план ещё не подтверждён. Реализация не начата.

## Согласованные решения

1. Цель — подготовка к будущим длинным диалогам; наблюдаемая регрессия производительности не заявлена.
2. Целевой объём — 1 000 сообщений, включая сообщения модели с Markdown и кодом длиной до 50 000 символов. Критерии измерения производительности предстоит согласовать.
3. Область задачи — отображение и прокрутка. Хранение диалогов и состав истории, отправляемой модели, не меняются.

## Факты текущей реализации

- Все сообщения отображаются в DOM; неизменённый Markdown повторно не рендерится, но обновление проходит по всему списку.
- Высоты сообщений переменные; Markdown, изображения и вложенное содержимое могут менять их после отображения.
- Прокрутка следует за генерацией у нижнего края и прекращает слежение при чтении истории.
- Видимый диалог содержит ошибки и остановленные сообщения; история запросов содержит только успешно завершённые пары.
- Автоматические проверки используют упрощённый Markdown и заданную геометрию. Реальные размеры и плавность требуют проверки в desktop Obsidian, принятом в предыдущем плане потокового отображения.

## Открытые ветви обсуждения

- Единица виртуализации и обращение с одним большим сообщением.
- Сохранение позиции при генерации, изменении ширины и позднем изменении высоты содержимого.
- Поиск, выделение текста и клавиатурная навигация по истории.
- Измеримые критерии и сценарии проверки.
- Технический подход, жизненный цикл Markdown и ограничения работы вне видимой области.

## Документация домена

Новые доменные термины пока не согласованы. Общий технический термин «виртуализация» не добавляется в глоссарий. Оснований для ADR пока нет.
