# Несколько фрагментов и целых заметок в одном сообщении

## Parent

Спецификация: https://github.com/AlexRaptor/Obsidian-AI-Helper/issues/41

## What to build

Пользователь собирает один вопрос из нескольких выделенных фрагментов разных заметок и целых вложений. Порядок упоминаний и точный выбор сохраняются; повторные упоминания не размножают один снимок, а пересечения и разные версии остаются различимыми в сообщении и запросе модели.

## Acceptance criteria

- [ ] После добавления фрагмента из «Плана» можно открыть «Итоги», выделить другой текст и добавить его в тот же черновик без потери первого упоминания и инструкции. Успешный запрос передаёт оба точных снимка; следующий вопрос использует их из истории.
- [ ] Разрешены несколько фрагментов одной заметки, разные части одной строки и пересекающиеся диапазоны. Они не объединяются автоматически и не заменяются целой заметкой.
- [ ] Повторы той же заметки, того же точного диапазона и того же сохранённого текста передают один снимок в пределах сообщения. Удаление одного повторения сохраняет остальные; после удаления последнего снимок не включается в запрос нового сообщения.
- [ ] Разные диапазоны с одинаковым текстом, разные исходные заметки и изменённые версии текста одного диапазона сохраняются как разные снимки. Совпадение названия и номеров строк не является достаточным основанием для объединения.
- [ ] В одном вопросе допускаются целые заметки и фрагменты, включая фрагменты целого вложения той же заметки. Целая заметка читается при отправке, фрагменты остаются зафиксированными при добавлении; модель может различить их происхождение и версии.
- [ ] Правки оригинала после добавления не меняют прежние фрагменты; новое выделение изменённого текста можно добавить отдельно. Дедупликация не переписывает снимки прежних сообщений.
- [ ] Без поиска весь набор вложений, история и резерв ответа учитываются в общем лимите. При недостаточном бюджете сохраняется весь черновик; нет частичной отправки или молчаливого усечения. Ошибка чтения явно прикреплённой целой заметки не допускает отправки только оставшихся вложений.
- [ ] Редактирование, удаление упоминаний, копирование видимого сообщения и смена локали сохраняют согласованную семантику всех частей смешанного черновика.
- [ ] Автоматические интеграционные сценарии проверяют основной пример двух заметок, повторы, пересечения, части одной строки, разные версии, смешанные вложения, фактический состав запросов и историю. Обновлённые регрессии и производственная сборка проходят; дополнительная ручная приёмка этой задачи не требуется.
