# Выбирать любую заметку хранилища через @ с фильтрацией по имени и пути

## Parent

Спецификация: https://github.com/AlexRaptor/Obsidian-AI-Helper/issues/33

## What to build

Расширить законченный сценарий обсуждения одной заметки: пользователь выбирает через @ не только текущую заметку, но любую Markdown-заметку хранилища, фильтруя список по имени и пути. Выбранная заметка передаётся снимком при отправке и остаётся в истории последующего обсуждения. На этом этапе достаточно фильтрации цельной подстрокой; несколько слов и пропуски букв добавляются отдельно.

## Acceptance criteria

- [ ] Список содержит все Markdown-заметки, включая исключённые из индексации папки. Построение индекса и embedding-модель для выбора не требуются.
- [ ] Без фильтра текущая заметка первая, остальные упорядочены по пути. При отсутствии текущей заметки список других файлов работает.
- [ ] Набираемый после @ фильтр ищет цельную подстроку в полном пути без учёта регистра; отбор охватывает название и папки.
- [ ] В списке различимы пути заметок с одинаковыми именами. При отсутствии результатов отображается локализованное сообщение, введённый текст сохраняется.
- [ ] Выбор произвольной заметки создаёт отдельное цветовое упоминание, привязывается к выбранному файлу и отправляет его актуальный снимок, независимо от текущей вкладки.
- [ ] Удаление упоминания и последующий выбор другого файла работают без остаточного контекста предыдущего выбора.
- [ ] Сохраняются правила обычного @, почты, кода, вставки, клавиатурного подтверждения, черновика, истории, проверки бюджета и ошибок первого сценария.
- [ ] Интеграционные проверки проходят через список и поле чата с наблюдением запросов. Русскоязычные данные покрывают одинаковые имена, пути, отсутствие текущей заметки и исключённую папку; сборка с проверкой типов проходит.
- [ ] Отдельная обязательная ручная проверка не требуется: каталог, фильтрация и состав отправленного снимка проверяются автоматически. Проверку самого компонента ввода не дублировать из первого сценария упоминаний.
