# Находить упоминаемые заметки несколькими словами и сокращённым вводом без пробелов

## Parent

Спецификация: https://github.com/AlexRaptor/Obsidian-AI-Helper/issues/33

## What to build

Пользователь фильтрует список упоминаний несколькими словами, частями пути и сокращением с пропуском букв, выбирает результат и обсуждает найденную заметку. Поиск project monexa и projemonex должен соответствовать согласованным примерам.

## Acceptance criteria

- [ ] Каждый разделённый пробелами токен должен совпасть с полным путём без учёта регистра; токены могут находиться в разных частях пути, не рядом и в любом порядке.
- [ ] Помимо цельной подстроки токен допускает совпадение последовательности букв с пропусками, включая разделители папок. Порядок введённых букв сохраняется; замены, перестановки и исправление опечаток не требуются.
- [ ] project monexa находит 1.Projects/Monexa.md, Docs/ProjectDescriptionMonexa/README.md и Monexa/Project.md, но не Projects/Another.md. Перестановка слов и изменение регистра сохраняют набор подходящих результатов.
- [ ] projemonex без пробелов находит 1.Projects/Monexa.md и Docs/ProjectDescriptionMonexa/README.md.
- [ ] Цельные совпадения ранжируются выше совпадений с пропусками, более компактные совпадения предпочтительнее разреженных. При одинаковой релевантности порядок определяется путём; конкретная числовая формула не фиксируется тестами.
- [ ] Приоритет текущей заметки сохраняется для списка без фильтра и не заменяет ранжирование отфильтрованных результатов.
- [ ] Многословный ввод остаётся частью фильтра до выбора или отказа; не создаёт вложений автоматически. Escape сохраняет введённый текст, а выбор результата передаёт снимок именно найденной заметки.
- [ ] Интеграционные проверки проходят через ввод фильтра, порядок видимых результатов, выбор и фактический запрос модели. Проверяют согласованные примеры и русскоязычные имена; производственная сборка с проверкой типов проходит.
- [ ] Обязательная ручная проверка не требуется: совпадения, порядок результатов и выбор правильного файла проверяются автоматически через чат.
