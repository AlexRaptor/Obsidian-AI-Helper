# Obsidian AI Helper

Плагин для Obsidian, добавляющий чат с LLM-моделью, доступной через OpenAI-совместимый API.

## Language

**Модель-сервер (model server)**:
OpenAI-совместимый сервис, на котором размещены модели. Идентифицируется адресом.
_Avoid_: API, бэкенд, LLM

**Модель (model)**:
Модель, предоставленная модель-сервером и выбранная пользователем для диалога или построения смысловых представлений текста.
_Avoid_: LLM, нейросеть

**Модель диалога (conversation model)**:
Модель, формирующая сообщения в ответ на сообщения пользователя и переданный контекст.
_Avoid_: чат-модель

**Embedding-модель (embedding model)**:
Модель, представляющая текст в виде вектора для поиска по смысловой близости.
_Avoid_: модель диалога (в значении embedding-модели)

**Индекс хранилища (vault index)**:
Поисковое представление содержимого заметок хранилища Obsidian, включённых в область индексации.
_Avoid_: база знаний

**Исключённая папка (excluded folder)**:
Папка хранилища, содержимое которой исключено из области индексации.
_Avoid_: скрытая папка

**Поиск по заметкам (note search)**:
Поиск фрагментов заметок хранилища, относящихся к вопросу пользователя, для подготовки сообщения модели диалога.
_Avoid_: поиск по чату

**Описание папки (folder description)**:
Отдельная Markdown-заметка о назначении папки, содержащая критерии включения и исключения заметок. Имя файла описания задаётся пользователем; описание относится к папке, в которой находится файл.
_Avoid_: служебный файл, промпт папки

**Рекомендация папки (folder recommendation)**:
Предложение места хранения существующей заметки или будущей заметки, описанной пользователем, основанное на описаниях папок и сопровождаемое объяснением. Решение о размещении принимает пользователь.
_Avoid_: автоматическая сортировка, классификация PARA

**Поиск папок (folder search)**:
Поиск папок хранилища по смыслу их описаний. Результат представляет папку и соответствующее описание.
_Avoid_: поиск по названиям папок

**Источник (source)**:
Заметка, найденные фрагменты которой использованы как контекст для сообщения модели диалога.
_Avoid_: источник знаний

**Фрагмент заметки (note fragment)**:
Часть текста заметки, которая индексируется и может быть отобрана как контекст для сообщения модели диалога.
_Avoid_: чанк, кусок

**Выделенный фрагмент (selected note fragment)**:
Часть текста заметки, которую пользователь явно выделил для передачи модели диалога.
_Avoid_: найденный фрагмент (в значении явно выделенного текста)

**Диалог (conversation)**:
Последовательность сообщений между пользователем и моделью. Каждому запросу отправляется полная история сообщений.
_Avoid_: сессия, чат-поток, обмен

**Сообщение (message)**:
Одна реплика пользователя или модели внутри диалога.
_Avoid_: запрос, ответ (в значении «сообщение»)

**Вложение заметки (note attachment)**:
Заметка, которую пользователь явно прикрепляет к сообщению, чтобы передать её содержимое модели диалога для обсуждения.
_Avoid_: источник (в значении явно прикреплённой заметки)

**Упоминание заметки (note mention)**:
Явное указание заметки в тексте сообщения, которое связывает сообщение с вложением этой заметки.
_Avoid_: ссылка (в значении упоминания для передачи содержимого модели)

**Снимок заметки (note snapshot)**:
Содержимое заметки на момент отправки сообщения, сохраняемое в диалоге для последующего обсуждения.
_Avoid_: текущая версия (в значении уже отправленного снимка)

**Упоминание выделенного фрагмента (selected fragment mention)**:
Явное указание выделенного фрагмента в тексте сообщения, связывающее сообщение с его снимком.
_Avoid_: цитата (в значении упоминания для передачи контекста)

**Снимок выделенного фрагмента (selected fragment snapshot)**:
Текст выделенного фрагмента на момент добавления его упоминания, сохраняемый для обсуждения в диалоге.
_Avoid_: текущий текст (в значении уже зафиксированного фрагмента)

**Потоковое сообщение модели (streamed model message)**:
Сообщение модели, текст которого поступает от модель-сервера частями и становится доступен для чтения до завершения генерации.
_Avoid_: анимация печати, чат-поток

**Ветка (branch)**:
Визуальное представление сообщения в чате: вертикальная цветная черта слева, ширина 3px. Черта ветки пользователя — `--interactive-accent` (акцент темы); черта ветки модели — нейтральный цвет (`--text-muted`).
_Avoid_: маркер, индикатор роли, акцент
