# Obsidian AI Helper

Плагин для Obsidian, добавляющий чат с LLM-моделью, доступной через OpenAI-совместимый API.

## Language

**Модель-сервер (model server)**:
OpenAI-совместимый сервис, на котором размещены модели. Идентифицируется адресом.
_Avoid_: API, бэкенд, LLM

**Модель (model)**:
Модель, предоставленная модель-сервером и выбранная пользователем для диалога или построения смысловых представлений текста.
_Avoid_: LLM, нейросеть

**Модель диалога (conversation model)**:
Модель, формирующая сообщения в ответ на сообщения пользователя и переданный контекст.
_Avoid_: чат-модель

**Embedding-модель (embedding model)**:
Модель, представляющая текст в виде вектора для поиска по смысловой близости.
_Avoid_: модель диалога (в значении embedding-модели)

**Индекс хранилища (vault index)**:
Поисковое представление содержимого заметок хранилища Obsidian, включённых в область индексации.
_Avoid_: база знаний

**Исключённая папка (excluded folder)**:
Папка хранилища, содержимое которой исключено из области индексации.
_Avoid_: скрытая папка

**Поиск по заметкам (note search)**:
Поиск фрагментов заметок хранилища, относящихся к вопросу пользователя, для подготовки сообщения модели диалога.
_Avoid_: поиск по чату

**Источник (source)**:
Заметка, найденные фрагменты которой использованы как контекст для сообщения модели диалога.
_Avoid_: источник знаний

**Фрагмент заметки (note fragment)**:
Часть текста заметки, которая индексируется и может быть отобрана как контекст для сообщения модели диалога.
_Avoid_: чанк, кусок

**Диалог (conversation)**:
Последовательность сообщений между пользователем и моделью. Каждому запросу отправляется полная история сообщений.
_Avoid_: сессия, чат-поток, обмен

**Сообщение (message)**:
Одна реплика пользователя или модели внутри диалога.
_Avoid_: запрос, ответ (в значении «сообщение»)

**Потоковое сообщение модели (streamed model message)**:
Сообщение модели, текст которого поступает от модель-сервера частями и становится доступен для чтения до завершения генерации.
_Avoid_: анимация печати, чат-поток

**Ветка (branch)**:
Визуальное представление сообщения в чате: вертикальная цветная черта слева, ширина 3px. Черта ветки пользователя — `--interactive-accent` (акцент темы); черта ветки модели — нейтральный цвет (`--text-muted`).
_Avoid_: маркер, индикатор роли, акцент
